# Конспектор

Локальное веб-приложение для разбора YouTube-видео. По ссылке на ролик оно скачивает субтитры, делает краткую выжимку и позволяет задавать ИИ вопросы про всё видео или про отдельный фрагмент. Все разборы и диалоги сохраняются.

Работает на Windows и macOS, на бесплатном тарифе Google Gemini.

## Возможности

- **Транскрипция с таймкодами.** Субтитры показываются рядом с плеером, текущая строка подсвечивается. Клик по таймкоду перематывает видео.
- **Выжимка.** Краткое содержание, ключевые мысли с таймкодами и вывод, кому видео полезно.
- **Вопросы к видео.** Чат с ИИ по содержанию ролика. Можно спрашивать про всё видео или про фрагмент (например, с 05:00 до 12:30). Границы фрагмента можно взять прямо из плеера кнопкой «сейчас».
- **История.** Все разобранные видео, выжимки и диалоги сохраняются на диск. Можно вернуться к любому видео и продолжить разговор.
- **Устойчивость к перегрузке.** Если Gemini занят, приложение само повторяет запрос и при необходимости переключается на запасную модель.

## Быстрый старт (Windows)

1. Распакуй архив в любую папку.
2. Дважды кликни `start.bat`.

Батник сам:

- найдёт Python или установит его через `winget` (после установки нужно запустить батник ещё раз);
- установит нужные библиотеки;
- при первом запуске откроет страницу Google AI Studio и попросит вставить API-ключ;
- запустит сервер и откроет приложение в браузере.

Окно cmd не закрывай, пока пользуешься приложением: это и есть сервер.

## Быстрый старт (macOS)

1. Распакуй архив (двойной клик по zip в Finder).
2. Дважды кликни `start.command`.

Скрипт сам:

- найдёт Python 3.10+ или установит его через Homebrew (если Homebrew нет, откроет python.org: установи Python и запусти скрипт ещё раз);
- создаст папку `.venv` с отдельным окружением и поставит туда библиотеки, не трогая систему;
- при первом запуске откроет Google AI Studio и попросит вставить API-ключ (Cmd+V, затем Enter);
- запустит сервер и откроет приложение в браузере.

Окно Терминала не закрывай, пока пользуешься приложением. Остановить сервер: Ctrl+C или закрыть окно.

### Если macOS не даёт запустить `start.command`

Файл скачан из интернета и не подписан разработчиком Apple, поэтому при первом запуске macOS может его заблокировать. Варианты, от простого к надёжному:

- **Правый клик → Открыть → Открыть.** Нужно только один раз.
- **Системные настройки → Конфиденциальность и безопасность**, внизу кнопка **«Всё равно открыть»** (на новых версиях macOS работает этот способ).
- **Через Терминал**, работает всегда. Открой Терминал, напиши `bash ` (с пробелом), перетащи `start.command` в окно Терминала и нажми Enter.

Если пишет «Permission denied», выполни в Терминале `chmod +x ` и перетащи файл, затем Enter.

## API-ключ Gemini

Ключ бесплатный, карта не нужна.

1. Открой [aistudio.google.com/apikey](https://aistudio.google.com/apikey) и войди через Google-аккаунт.
2. Нажми **Create API key** и скопируй ключ.
3. Ключ хранится в файле `.env` рядом с `app.py`:
   ```
   GEMINI_API_KEY=AIzaSy...
   ```

`start.bat` создаёт этот файл сам. Если нужно поменять ключ, отредактируй `.env` или удали его и запусти батник заново.

> Не публикуй `.env` (например, на GitHub). Добавь его в `.gitignore`.

## Ручной запуск

Если батник не нужен или у тебя не Windows:

Windows:

```
pip install -r requirements.txt
python app.py
```

macOS / Linux:

```
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

Браузер откроется сам на http://127.0.0.1:5055. Нужен Python 3.10 или новее.

## Как пользоваться

1. Вставь ссылку на видео и нажми **Разобрать видео**. Подходят ссылки вида `youtube.com/watch?v=...`, `youtu.be/...`, `shorts/...`, `live/...`.
2. Слева появятся плеер и субтитры, справа — выжимка и чат.
3. Чтобы спросить про фрагмент, выбери **Фрагмент** и укажи границы (`05:30` или `1:02:05`). Удобно поставить видео на паузу и нажать **сейчас**.
4. Таймкоды в выжимке и ответах кликабельны: плеер перемотается на это место.
5. Кнопка **История** показывает все разобранные видео.

## Структура проекта

```
yt-summary\
  start.bat             запуск в один клик (Windows)
  start.command         запуск в один клик (macOS)
  app.py                веб-сервер (Flask): принимает запросы страницы
  core.py               логика: субтитры, сохранение, запросы к Gemini
  templates\index.html  интерфейс
  requirements.txt      список библиотек
  .env                  API-ключ (создаётся при первом запуске)
  results\              сохранённые разборы (создаётся автоматически)
  .venv\                окружение Python на macOS (создаётся автоматически)
```

`core.py` ничего не знает про веб: всю логику можно вызывать и тестировать отдельно. `app.py` только связывает страницу с функциями из `core.py` и превращает ошибки в понятные сообщения.

## Где хранятся данные

Каждое видео — один файл `results\<ID видео>.json`. В нём:

| Поле | Что внутри |
|---|---|
| `title` | название видео |
| `language` | язык субтитров |
| `segments` | субтитры с таймкодами |
| `summary` | выжимка |
| `chat` | диалог: вопросы, ответы, фрагмент, время |
| `created`, `updated` | когда видео разобрано и когда была последняя активность |

Чтобы сделать резервную копию, достаточно скопировать папку `results`. Повторное открытие сохранённого видео не тратит лимиты YouTube и Gemini.

## Настройки

В начале `core.py`:

| Параметр | Что меняет |
|---|---|
| `LANGUAGES` | в каком порядке искать субтитры (`ru`, `uk`, `en`) |
| `MODELS` | модели Gemini: основная и запасная |
| `RETRIES_PER_MODEL` | сколько раз повторять запрос при перегрузке |
| `MAX_HISTORY` | сколько последних реплик диалога ИИ учитывает |

Порт сервера (по умолчанию 5055) меняется строкой `PORT=...` в `.env`.

Алиасы `gemini-flash-latest` и `gemini-flash-lite-latest` всегда указывают на свежие модели Google, поэтому после выхода новых версий код менять не нужно.

## Частые проблемы

**«Модели Gemini сейчас перегружены» / ошибка 503.** Временная перегрузка на стороне Google, бывает на бесплатном тарифе. Подожди минуту и повтори. Текст вопроса при этом не теряется.

**Ошибка 429.** Исчерпан лимит бесплатного тарифа (запросов в минуту или в день). Подожди или попробуй завтра.

**«У этого видео нет субтитров».** У ролика нет ни ручных, ни автоматических субтитров на русском, украинском или английском. Такие видео пока не поддерживаются.

**macOS: `ModuleNotFoundError` или странные ошибки после обновления Python.** Удали папку `.venv` и запусти `start.command` заново: окружение пересоздастся.

**«Не найден GEMINI_API_KEY».** Нет файла `.env` или в нём ошибка. Строка должна быть ровно `GEMINI_API_KEY=ключ`, без пробелов и кавычек, а файл должен называться `.env`, а не `.env.txt`.

**Страница не открывается.** Проверь, что окно cmd или Терминала с сервером открыто и в нём нет ошибки. Если браузер не открылся сам, перейди вручную на http://127.0.0.1:5055

**«Address already in use» / порт занят.** Порт 5055 занят другой программой. Добавь в `.env` строку `PORT=5056` (или любой другой свободный номер) и перезапусти. Порт 5000 на macOS лучше не использовать: его занимает AirPlay.

**YouTube не отдаёт субтитры (`RequestBlocked`, `IpBlocked`).** YouTube временно ограничил запросы с твоего IP. Обычно проходит само через некоторое время.

## Ограничения

- Работают только видео с субтитрами.
- Приложение локальное: доступно только на твоём компьютере.
- На бесплатном тарифе Google может использовать запросы для улучшения своих моделей. Для публичных видео это обычно не важно.

## API сервера

Для тех, кто захочет подключить свой интерфейс или бота:

| Метод | Адрес | Что делает |
|---|---|---|
| POST | `/api/video` | `{url}` → субтитры, выжимка, диалог |
| POST | `/api/summary` | `{video_id, force}` → выжимка |
| POST | `/api/ask` | `{video_id, question, start, end}` → ответ ИИ |
| POST | `/api/chat/clear` | `{video_id}` → очистить диалог |
| GET | `/api/history` | список разобранных видео |
| POST | `/api/video/delete` | `{video_id}` → удалить разбор |

Все ответы в JSON. При ошибке возвращается `{"error": "описание"}`.
